WGH RAG 嵌入式问答 Widget

本页演示第三方页面通过 JS 片段注入 iframe。请在管理端「开放平台 → 免登录分享」创建一个 WINDOW 范围的分享链接，并开启「允许嵌入」、填写域名 / IP 白名单后， 把 token 粘贴到下方输入框点击「加载 Widget」。

授权是服务端校验的：widget.js 会先请求 /api/public/share/{token}/embed/authorize，浏览器自动携带真实 Origin； 未命中白名单时不会加载 iframe，而是在下方容器内展示可读的拒绝原因。

演示白名单拒绝：把当前页面域名（如 localhost）从分享链接的域名白名单中移除后重新加载， 即可看到“来源 xxx 不在嵌入白名单内”。删除所有域名与 IP 白名单后，开启嵌入将不限制来源。 缺少 Origin/Referer 的请求默认拒绝（除非客户端 IP 命中 IP 白名单）。

也可以直接在地址栏使用 ?token=xxx 打开本页自动加载。

<div id="wgh-widget"></div>
<script src="http://localhost:5173/widget.js"
        data-token="YOUR_TOKEN"
        data-base="http://localhost:5173"
        data-api-base="http://localhost:8080"
        data-container="wgh-widget"
        data-height="640px"></script>

提示：跨域嵌入时，服务端已按 Origin/Referer 与 IP 白名单校验； 浏览器级兜底还需在网关/静态站点配置 CSP frame-ancestors 允许嵌入域名。 当 API 与分享页不同域时，可通过 data-api-base 指定 API 地址。
